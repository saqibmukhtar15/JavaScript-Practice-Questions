Answers

Q1 Ans.
Jab ek variable ke multiple values ko check karna ho.

Q2 Ans.
let dayNumber = 3;
switch (dayNumber) {
    case 1: console.log("Monday");
break;
    case 2: console.log("Tuesday");
break;
    case 3: console.log("Wednesday");
break;
    case 4: console.log("Thursday");
break;
    case 5: console.log("Friday");

break;
    case 7: console.log("Sunday");

Q3 Ans.

    case "home": console.log("Welcome to the Homepage!");
break;

break;
    case "setting": console.log("Change your account preferences here.");
break;

console.log("404: Page Not Found");

Q4 Ans.
Output: Holiday

Q5 Ans.
Diffrence between switch and if else:
switch: Ek single variable par focus karta hai. Bahut saare options ke liye zyada saaf aur readable hai. Mostly equality (===) check karta hai.
if else: multiple conditions check karta hai. Zyada nested hone par Code ko padhna aur samajhna bohat mushkil ho jata hai. Kisi bhi tarah ki boolean condition check kar sakta hai.

Q6 Ans.
let num1 = 10;
let num2 = 5;
let operator = "*";
switch (operator) {
    case "+": console.log("Result: " + (num1 + num2)); break;
    case "-": console.log("Result: " + (num1 - num2)); break;
    case "*": console.log("Result: " + (num1 * num2)); break;
    case "/":
        if(num2 !== 0) { console.log("Result: " + (num1 / num2)); }
        else { console.log("Error: Division by zero"); }
        break;
    default: console.log("Error: Invalid Operator");
}

Output: Result: 50

Q6 Ans.
Jab ek loop ke andar dusra loop maujood ho, toh use Nested Loop kehte hain.

Example: Digital Clock.
Ek ghari nested loop ki behtareen misal hai. Jab tak minute wala loop 60 baar nahi ghumta, tab tak ghante (hour) wala loop agle number par nahi jata.

Outer Loop: Hours,
Inner Loop: Minutes

for (let hour = 1; hour <= 3; hour++) {
for (let minute = 0; minute < 60; minute++) {
console.log("Hour: " + hour + " - Minute: " + minute);
}
}
